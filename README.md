# MechCrypto NGCC Results

This repository presents MechCrypto's validated principal results for 115 first-round NGCC candidates. Each candidate has one result PDF, a short statement of the principal result, and a unified code directory when source code is available.

The results contain 23 Critical, 10 High, 13 Medium, 62 Low, and 7 Info principal results. Severity, evidence status, and layer are reported separately; the conditions attached to each claim are part of the result.
